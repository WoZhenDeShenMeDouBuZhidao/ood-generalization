# FITCE Semantic-Group Gradient Aggregation

## Goal

Test whether FITCE should remove the column-level assumption that every one-hot category receives the same share of its semantic feature's importance. The active baseline already uses `categorical_encoding=auto` and `semantic_expansion_policy=split`, which preserves total semantic target mass but still aligns every expanded model column separately.

The candidate instead constrains only the total gradient importance of each semantic feature, leaving the allocation among its categories to CE and the data.

## Implementation

Added `--grad-alignment-space {model,semantic}` with backward-compatible default `model`:

- `model`: retain the active column-level FITCE behavior. For one-hot features, use `semantic_expansion_policy=split`, so each category receives `w_s / k_s` target weight.
- `semantic`: compute the existing train-standard-deviation-scaled Grad-L2 signal for every model column, sum signals belonging to the same semantic feature, and only then apply temperature, normalization, and the gradient target loss.

For semantic feature `s` with model columns `C_s`, the candidate uses:

```text
g_j = mean((train_std_j * d margin / d x_j)^2)
G_s = sum(g_j for j in C_s)
q_s = G_s^(1 / tau) / sum_t G_t^(1 / tau)
L_grad = -sum_s p_s log(q_s)
```

`p_s` comes directly from the unexpanded semantic rank-derived importance weights. Aggregation occurs before temperature and normalization; summing already-normalized column probabilities would reintroduce category-count dependence when `tau != 1`. Numerical and integer-encoded features are singleton groups and are unchanged.

Grouped diagnostic Grad-L2 and Grad-Prob terms use the same semantic groups as the optimized loss. The first-layer-weight target remains model-column based and separate from `grad_alignment_space`; it is inactive in this experiment because `weight_scale=0`.

## Protocol

- Datasets: the eight datasets whose `auto` representation is natively one-hot: WHYSHIFT Accident plus TableShift Diabetes Readmission, NHANES Lead, NHANES Cholesterol, ANES, ACS Food Stamps, BRFSS Diabetes, and BRFSS Blood Pressure.
- The ten natively integer-encoded datasets were not rerun because every semantic group contains one model column and the two alignment spaces are mathematically identical.
- Baseline: active column-level split FITCE from `categorical_one_hot_fitce_trainstd_semantic_split_r3`.
- Candidate: auto-encoding semantic-group FITCE from `fitce_auto_semantic_group_trainstd_rank_reg0p1_tau2_r3`.
- Both use the same native-equivalent cached tensors, GPT-5.4 semantic `rank/rank`, `importance_scale=train_std`, `reg_scale=0.1`, `loss_lambda=1`, `loss_alpha=1`, `weight_scale=0`, `grad_prob_temperature=2`, `reweighting_scope=all`, and no warmup.
- Seeds: `9803`, `38224`, and `8113`; three repeats.
- Training: learning rate `1e-4`, train/eval batch sizes `256/2048`, patience `200`, and maximum `5000` epochs.
- ID selection: ID balanced accuracy + ID macro F1.
- OOD selection: OOD mean/worst balanced accuracy + OOD mean/worst macro F1.
- Curves and SHAP were not requested for this performance screen.
- Eight jobs ran concurrently across four RTX 4090 GPUs and completed in 14.3 minutes with zero failures.

## Active All-18 Impact

Composing each candidate with the unchanged ten integer/no-op FITCE results gives:

| Active FITCE setting | FITCE-CE ID | FITCE-CE OOD |
|---|---:|---:|
| column alignment + split target | +0.0002 | -0.0022 |
| semantic-group alignment | -0.0011 | -0.0082 |
| **Group minus column** | **-0.0013** | **-0.0060** |

Semantic grouping therefore turns the active all-18 ID result from slight parity/advantage into a deficit and approximately quadruples the small OOD deficit.

## Interpretation

- The result does not support the hypothesis that column-level equal category targets are a remaining FITCE performance problem. Removing that constraint consistently lowers OOD selection under the current hyperparameters.
- The regression is not caused by a representation or data difference: every paired result uses the same native-equivalent cache, seeds, optimizer, prior, and FITCE settings.
- A fixed `reg_scale=0.1` may have a different effective parameter-gradient strength after changing the alignment space, but the unretuned candidate is unfavorable enough that it is not adopted as an improvement.
- Contrast-centered categorical signals address a different issue: full one-hot gradients contain a non-identifiable common component, while valid category changes depend on gradient contrasts. This remains theoretically plausible but has no current empirical support. Before a contrast-centered training sweep, measure common-mode versus contrast energy and test whether their ratio is unusually high on the datasets where grouping regressed.

## Validation

- All eight candidate artifacts passed status, repeat-count, cache, ranking, alignment-space, and FITCE hyperparameter validation.
- A focused loss test verified that two category signals are summed before the semantic probability calculation, while identity groups exactly reproduce the default model-alignment loss.
- Python compilation and `git diff --check` passed; all GPUs were empty after completion.

## Decision

Do not adopt semantic-group gradient aggregation and do not proceed directly to a contrast-centered full sweep. Keep the active FITCE setup at `categorical_encoding=auto`, `semantic_expansion_policy=split`, and `grad_alignment_space=model`. Retain semantic grouping as an explicit diagnostic option, but use the existing column-level split FITCE for subsequent improvement experiments.

# Candidate FITCE Improvements from the Encoding-Stratified Results

## Motivation and Existing Evidence

This section records candidate methods and the evidence required before they
are treated as improvements. None of the methods below has been evaluated yet,
and the active FITCE configuration remains unchanged.

Directly averaging the active auto-encoding dataset rows from the 2026-08-05
comparison gives:

| Active representation | Datasets | FITCE-CE ID | FITCE-CE OOD |
|---|---:|---:|---:|
| integer/no-op | 10 | -0.0037 | -0.0083 |
| native one-hot with `split` | 8 | +0.0052 | +0.0053 |

The five largest active ID deficits are Public Coverage, Travel Time, Health
Insurance, Income, and Taxi; the five largest active OOD deficits are College
Scorecard, Public Coverage, Income Poverty Ratio, Income, and Employment. All
ten entries use the native integer/no-op path. This is stronger evidence for
an integer-representation-specific issue than for another one-hot aggregation
change.

The semantic ranking cards for the eight ACS tasks plus Taxi contain 151
features, of which 142 are categorical, ordinal categorical, or boolean
categorical. College Scorecard is a different case: 107 of its 118 ranking-card
features are continuous, so its large OOD deficit may instead reflect the
high-dimensional dense rank target or a separate optimization issue.

## 1. Encoding-Aware Importance Signal

The current signal for every model column is

```text
g_j = mean((train_std_j * d margin / d x_j)^2)
```

For a nominal category stored as an integer, this derivative assumes a
continuous, equally spaced path through arbitrary category codes. TrainStd
removes coordinate-unit dependence but cannot give this path categorical
meaning.

The proposed hybrid signal is:

- continuous and genuinely ordinal features: keep the current TrainStd-scaled
  margin-gradient signal;
- nominal and boolean integer categorical features: use the expected squared
  margin change under a valid category replacement sampled from the training
  categories.

```text
g_j = E[(margin(x with x_j replaced by c') - margin(x))^2]
```

Both components measure a margin change under a meaningful feature
perturbation and can be differentiated with respect to the model parameters.
The categorical estimator can be sampled or vectorized to control the extra
forward-pass cost.

Before a training sweep, compare the current gradient signal, the categorical
counterfactual signal, and margin SHAP at best checkpoints on the ten
integer/no-op datasets. Proceed to an all-18 hybrid FITCE screen only if the
counterfactual signal has lower SHAP RankDist on a clear majority and its
advantage is concentrated in the datasets where active FITCE trails CE.

## 2. Rank-Only Gradient Alignment

The GPT prior used by active FITCE supplies an ordinal ranking, but the current
loss converts ranks to `n, n-1, ..., 1`, normalizes those values, and minimizes
cross-entropy to the complete target distribution. It therefore treats the
linear rank weights as exact relative importance magnitudes. At `tau=2`, a
19-feature task is driven toward an approximately `19:1` top-to-bottom scaled
RMS-gradient ratio, while the 118-feature College Scorecard task is driven
toward approximately `118:1`. Those ratios are introduced by the mapping and
were not supplied by GPT.

The completed Top-5 margin-SHAP sweep provides a trade-off signal:

| Reg scale | ID | OOD | SHAP RankDist |
|---:|---:|---:|---:|
| 0.03 | 1.4554 | 2.5917 | 0.3811 |
| 0.30 | 1.4225 | 2.5556 | 0.3572 |

Moving from `0.03` to `0.30` improves SHAP RankDist by only `0.0239` while
losing `0.0329` ID and `0.0361` OOD selection. This is consistent with the
dense distribution target continuing to reshape magnitudes after much of the
useful ordering has already been obtained.

A candidate ordinal loss should penalize pairwise rank inversions and stop
pushing once a small ordering margin is satisfied, for example:

```text
L_rank = mean(max(0, margin - (log(signal_i) - log(signal_j))))
```

This tests whether FITCE can preserve the GPT ordering without imposing the
arbitrary linear rank-weight ratios. The first implementation should retain
the active `categorical_encoding=auto`, `semantic_expansion_policy=split`, and
`grad_alignment_space=model` settings so only the loss geometry changes.

## 3. Conflict-Aware Regularization

Before adding gradient projection, conflict gating, or an adaptive regularizer
scale, record the following during training for every dataset:

```text
cosine(d CE / d theta, d FITCE / d theta)
norm(d FITCE / d theta) / norm(d CE / d theta)
```

Adopt a conflict-aware optimizer only if negative cosine frequency or the norm
ratio is systematically larger on datasets where FITCE trails CE. If that
relationship is absent, gradient surgery would weaken the regularizer without
evidence that it addresses the observed deficit.

## Proposed Order

1. Run the integer categorical counterfactual diagnostic without changing the
   active training method.
2. If its evidence gate passes, evaluate the hybrid importance signal on all
   18 real-world datasets against CE and the active FITCE baseline.
3. Evaluate rank-only alignment as a separate all-18 candidate, without
   combining it with the hybrid signal in the first screen.
4. Test conflict-aware optimization only after the parameter-gradient cosine
   and norm diagnostics support it.
5. Keep the first-layer-weight term inactive with `weight_scale=0` throughout
   these gradient-term experiments.
