## Ranking Artifact To Feature-Loss Weights

Goal:

- Add a shared helper that converts GPT ranking artifacts into
  `FEATURE_LOSS_WEIGHTS`.
- Support all four ranking methods:
  - `rank`
  - `score`
  - `score_all`
  - `seq`
- Use rank-position weights: for `n` features, rank 1 receives `n`, rank 2 receives
  `n - 1`, and the last feature receives `1`.

Implementation:

- Added `src/ranking.py`:
  - `ranking_artifact_path(dataset, method, model_name="gpt-5.5")`
  - `ranking_to_feature_loss_weights(ranking, feature_index)`
  - `feature_loss_weights_from_ranking(dataset, feature_index, method, model_name="gpt-5.5")`
- Updated `run_acsincome.py` to use:
  - `FEATURE_RANKING_METHOD = "score_all"`
  - `feature_loss_weights_from_ranking(DATASET, FEATURE_INDEX, method=FEATURE_RANKING_METHOD)`

Verification:

- `python -m py_compile src/ranking.py run_acsincome.py`
- Confirmed ACSIncome conversion for `rank`, `score`, `score_all`, and `seq`.
- Confirmed all 8 ACS tasks can load all 4 ranking artifacts and produce exactly
  descending weights `n..1`.
