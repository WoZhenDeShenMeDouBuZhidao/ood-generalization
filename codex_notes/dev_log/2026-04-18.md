### ACSIncome Resampling Experiment

固定設定：

- `MLP`
- pure CE (`LOSS_NAME="cross_entropy"`)
- train/val state: `PR`
- OOD states: 46 states, same as `run_acsincome.py`
- fixed seeds:
  - `9803`
  - `38224`
  - `8113`
  - `4854`
  - `98825`
- `TRAIN_BATCH = 256`
- `EVAL_BATCH = 2048`
- `LR = 1e-4`
- `PATIENCE = 500`
- `MAX_EPOCHS = 5000`

5-seed result:

- no-resampling fixed-seed baseline:
  - `ID = 0.9140`
  - `OOD MEAN = 0.7063`
  - `OOD WORST = 0.6166`
- train-only balanced oversampling:
  - `ID = 0.8470`
  - `OOD MEAN = 0.7594`
  - `OOD WORST = 0.7203`

Conclusion:

- ACSIncome label imbalance 是 OOD WORST 的重要瓶頸
- balanced oversampling 對 OOD 非常有效：
  - `OOD MEAN: 0.7063 -> 0.7594`
  - `OOD WORST: 0.6166 -> 0.7203`
- 但 ID 明顯下降：
  - `ID: 0.9140 -> 0.8470`
- 因此 resampling 更像 OOD upper-bound / tradeoff 訊號，而不是可以直接取代 fixed-seed baseline 的 final setting
- 下一步可先討論 / 嘗試 loss reweighting 或 class-weighted CE，看能否保留 OOD gain 並降低 ID drop
