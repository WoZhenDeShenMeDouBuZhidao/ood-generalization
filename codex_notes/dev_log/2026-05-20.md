## FeatureImportanceTargetCELoss Lambda/Alpha Grid Search

Goal:

- Optimize `feature_importance_target_ce` loss hyperparameters for the feature-importance target terms.
- Search `grad_scale` and `weight_scale` via a more interpretable `(LOSS_LAMBDA, LOSS_ALPHA)` parameterization.
- Record every grid combination's ACS task Accuracy/F1 details first, then decide the target selection metric.

Runner interface update:

- Renamed ACS runner environment variables to remove the old `ACS_` prefix:
  - `DEVICE`
  - `RANKING_METHOD`
  - `FEATURE_WEIGHT_MODE`
- Added:
  - `LOSS_LAMBDA`
  - `LOSS_ALPHA`
  - `REPEAT`
- The loss maps:
  - `grad_scale = LOSS_LAMBDA * LOSS_ALPHA`
  - `weight_scale = LOSS_LAMBDA * (1.0 - LOSS_ALPHA)`
- Default `LOSS_LAMBDA=5.0` and `LOSS_ALPHA=0.4`, matching the previous `grad_scale=2.0`, `weight_scale=3.0` setting.

Run protocol:

- Ranking source: `RANKING_METHOD=score_all`
- Feature weights: `FEATURE_WEIGHT_MODE=score`, i.e. `score_mean` direct weights.
- Loss: `feature_importance_target_ce`
- `REG_SCALE = 1.0`
- Fixed loss kwargs:
  - `reweighting=True`
  - `suppress_scale=6.0`
  - `target_power=1.0`
  - `importance_scale="train_std"`
- Full grid:
  - `LOSS_LAMBDA in {0, 0.5, 1, 2, 4, 5, 8, 16}`
  - `LOSS_ALPHA in {0, 0.25, 0.4, 0.5, 0.75, 1.0}`
  - `LOSS_LAMBDA=0` is run once with `LOSS_ALPHA=0.4` because alpha is irrelevant when total target strength is zero.
- Budget:
  - `REPEAT=5` for every grid configuration and every ACS task.
  - Seeds remain `[9803, 38224, 8113, 4854, 98825]`.
- Log root:
  - `acs_tasks/loss_grid_logs/fitce_score_all_direct_20260520_125438`
