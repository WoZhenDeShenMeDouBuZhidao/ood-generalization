# Real-World Dataset OOD Severity Ranking

## Question

FITCE and LAAT may trail CE because the OOD shift in many real-world test sets
is too weak for an OOD-oriented prior to help. Rank the 18 real-world datasets
by the performance drop of the current reproducible CE, then inspect whether
the current FITCE closes or widens its gap to CE under stronger shift.

## Definition and Protocol

Selection is balanced accuracy plus macro F1. OOD degree is defined so that a
larger positive value means a larger CE performance drop and therefore a more
severe shift:

```text
OOD degree = CE ID selection - CE OOD selection
           = (CE ID balanced accuracy + CE ID macro F1)
             - (CE OOD balanced accuracy + CE OOD macro F1)
```

- Produce separate rankings using OOD mean and OOD worst.
- CE is the current reproducible CE: the first three matched repeats of
  `ce_grad_l2_stability_r5`, with seeds `9803`, `38224`, and `8113`.
- FITCE is the active all-feature baseline: GPT-5.4 semantic `rank/rank`,
  `grad_alignment_top_p=1.0`, auto categorical encoding, semantic expansion
  `split`, model-space gradient alignment, `importance_scale=train_std`,
  `reg_scale=0.1`, `tau=2`, and the same three seeds.
- `ID gap` and `OOD gap` are `FITCE - CE`; positive means FITCE is better.
- `OOD gap - ID gap` is positive when FITCE improves relative to CE after
  moving from ID to OOD, even if FITCE still remains below CE in absolute
  performance.
- All 18 CE/FITCE pairs passed result, configuration, repeat-count, and
  matched-seed validation.

## Severity versus FITCE Gap

Spearman correlations use all 18 dataset-level values.

| OOD definition | Severity vs OOD FITCE-CE gap | Severity vs (OOD gap - ID gap) |
|---|---:|---:|
| Mean | rho=-0.214, p=0.395 | rho=+0.393, p=0.106 |
| Worst | rho=-0.028, p=0.913 | **rho=+0.531, p=0.023** |

OOD severity has no detectable relationship with the absolute FITCE-CE OOD
gap. However, worst-case severity is positively associated with FITCE improving
relative to its own ID gap. This is partial support for the hypothesis: stronger
worst-case shift helps FITCE catch up relative to its ID deficit, but does not
generally make FITCE beat CE in absolute OOD performance.

## Case-Study Candidates

The OOD mean and worst top-five rankings overlap on four datasets:

- `acs/acshealthinsurance`: FITCE remains below CE, but its gap shrinks from
  `-0.01674` ID to `-0.00568` OOD worst.
- `acs/acsmobility`: strongest relative recovery; the gap moves from `-0.05945`
  ID to nearly tied (`-0.00004`) at OOD worst.
- `whyshift/accident`: FITCE is already slightly above CE in ID, OOD mean, and
  OOD worst.
- `acs/acsemployment`: negative control; FITCE moves from `+0.00131` ID to
  `-0.01079` OOD worst despite strong shift.

Additional targeted cases:

- `acs/acstraveltime`: worst-specific positive case, moving from `-0.01210` ID
  to `+0.01008` OOD worst.
- `tableshift/college_scorecard`: strong mean shift but negative relative
  behavior, moving from `-0.00116` ID to `-0.01550` OOD.

Use Mobility and Health Insurance as primary positive-recovery cases, Accident
as a positive-performance case, and Employment plus College Scorecard as

single worst environment rather than mean OOD performance.

## Synthetic OOD CE, FITCE, and Remove-Spurious Rerun

### Question and Dataset Change

Rerun CE and FITCE on all five synthetic datasets under the current Balanced
Accuracy/Macro-F1 protocol. For `categorical_integer` and
`categorical_onehot`, remove `causal_continuous_1p25` and
`causal_continuous_0p75` at both the data and model levels. Their stable causal
signal then comes only from `causal_binary`, `causal_ordinal`, and
`causal_nominal`; the continuous spurious shortcut and all noise features
remain available.

- The two removed features are original indices `0` and `1` and use a separate
  `rm_0-1` data cache.
- The resulting model widths are 8 for `categorical_integer` and 18 for
  `categorical_onehot`; `simple`, `range`, and `multi_spurious` are unchanged.
- Each dataset has `train=6000`, `validation=2000`, one 4,000-row ID test, and
  four 4,000-row OOD tests: `ood_weak`, `ood_independent`,
  `ood_heterogeneous`, and `ood_reverse`.

### Protocol

- `REPEAT=3`, seeds `9803`, `38224`, and `8113`; `PATIENCE=200`,
  `MAX_EPOCHS=5000`, `LR=1e-4`, train batch 256, and eval batch 2048.
- All methods use the full synthetic data and `reweighting=off`.
- CE uses ordinary cross entropy.
- FITCE uses the exact oracle prior, all model features, logit-margin
  gradients, gradient term only, `reg_scale=10`, `tau=2`, model-space
  alignment, and `importance_scale=train_std`.
- OOD selection is `OOD Mean BAcc + OOD Worst BAcc + OOD Mean Macro-F1 + OOD
  Worst Macro-F1`.
- All `mean +/- range` cells are means and 95% Student-t confidence-interval
  ranges over the three matched model seeds. Macro confidence intervals use
  seed-matched averages across the five datasets.
- Remove Spurious (Optimal) uses the same CE training path after additionally
  removing every `spurious_*` feature. Noise remains; "Optimal" denotes the
  oracle feature set, not guaranteed optimization performance.
- All 15 result files passed status, repeat, seed, feature-removal, cache, and
  hyperparameter validation. No LAAT or historical result is reused in this
  comparison.

### Findings

- Removing the continuous causal features creates the intended stronger
  categorical stress test. CE retains about `0.974` ID BAcc/Macro-F1, but its
  OOD-worst BAcc/Macro-F1 falls to about `0.371/0.370` with integer encoding
  and `0.462/0.461` with one-hot encoding.
- Both categorical variants move into the severe end of the synthetic suite.
  `categorical_integer` has the largest mean OOD degree (`+0.7720`) and the
  second-largest worst degree (`+1.2068`); `categorical_onehot` reaches
  `+0.6547` mean and `+1.0274` worst.
- FITCE is below CE on ID for every dataset but above CE on both OOD mean and
  OOD worst for every dataset. Across the five datasets, macro ID selection
  drops from `1.9624` to `1.8091` (`-0.1533`), while OOD selection increases
  from `2.2231` to `3.5349` (`+1.3118`).
- On the new categorical tests, FITCE's mean/worst OOD gaps are
  `+0.3657/+0.7091` for integer and `+0.5246/+0.8827` for one-hot. The combined
  OOD-selection gains are therefore `+1.0748` and `+1.4073`, respectively,
  despite ID costs of `-0.2851` and `-0.1142`.
- One-hot FITCE is much more stable than integer FITCE. Its three per-seed OOD
  selections are `3.6060`, `3.6339`, and `3.6339`; integer gives `3.4311`,
  `3.3110`, and `2.2317`, producing the wide `2.9913 +/- 1.6408` interval.
  Integer encoding therefore remains an optimization/representation concern,
  and its mean should not be treated as a precise effect estimate at R3.
- Remove Spurious has macro OOD selection `3.6296`, compared with FITCE
  `3.5349`; the FITCE-minus-Optimal gap is `-0.0947`. The unstable integer
  FITCE and range Optimal seeds prevent treating this R3 macro gap as a robust
  method difference.
- FITCE effectively matches the oracle feature set on `simple`,
  `categorical_onehot`, and `multi_spurious`: absolute OOD-selection gaps are
  at most `0.0021`, and every paired interval contains zero.
- The two unstable cases drive the macro difference. Integer FITCE is
  `-0.6271` below Optimal because its third seed collapses, while
  Optimal is stable at `3.6131/3.6176/3.6245`. On `range`, FITCE is
  `+0.1515`, but Optimal's third seed selects epoch 23 and falls to
  `3.0938` versus `3.6978/3.6959` for the other seeds. Neither R3 mean is a
  reliable method advantage.
- This rerun strengthens the positive-control evidence: with an exact prior
  and shifts that directly break training shortcuts, FITCE trades ID accuracy
  for large OOD gains. It still does not prove that weak shift alone explains
  the real-world deficit because synthetic FITCE uses an oracle prior,
  `reg_scale=10`, balanced generated data, and no class reweighting.
