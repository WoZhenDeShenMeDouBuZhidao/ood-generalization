## LLM-Select Ranking Methods

Goal:

- Add the other LLM-Select feature-prior elicitation mechanisms after reading the first
  13 pages of `LLM-Select: Feature Selection with Large Language Models.pdf`.
- First test only on `acsincome`.

Paper takeaway:

- LLM-Select defines three methods:
  - `LLM-Score`: query one feature at a time for a numerical score, then rank by score.
  - `LLM-Rank`: query once for a complete ranking.
  - `LLM-Seq`: greedily select the next feature given already selected features.
- The paper uses greedy decoding by default and also studies self-consistency with
  `T=0.5` and 5 samples for score-style outputs.

Implementation:

- Extended `rank_features.py`:
  - `--method rank`
  - `--method score`
  - `--method seq`
  - `--method all`
- Default test target is now `--dataset acsincome`.
- Added method-specific output files:
  - `acs_tasks/acsincome/rankings/gpt-5.5_rank_feature_ranking.json`
  - `acs_tasks/acsincome/rankings/gpt-5.5_score_feature_ranking.json`
  - `acs_tasks/acsincome/rankings/gpt-5.5_seq_feature_ranking.json`
- `src/utils.py::call_llm` now accepts `temperature` and returns:
  - `content`
  - `input_tokens`
  - `output_tokens`
  - `total_tokens`
- Ranking JSON now stores:
  - method-level `token_usage`
  - each raw LLM call's prompt, content, and token usage
  - parsed final ranking
- Added retry/backoff knobs for temporary API cooldowns:
  - `--max-retries`
  - `--retry-sleep`
- Added score sampling knobs:
  - `--score-samples`
  - `--score-temperature`
  - `--call-delay`

## Accuracy/F1 Metric Expansion

Goal:

- Track both accuracy and binary F1 under the same sub-metrics:
  - `ID`
  - `OOD MEAN`
  - `OOD WORST`
  - `OOD STD`
- Plot F1 curves together with accuracy curves.

Implementation:

- `src/trainer.py`
  - computes binary class-1 F1 for train and validation at every epoch.
  - computes per-OOD-dataset accuracy and F1 for the best validation-accuracy model.
- `src/main.py`
  - still selects the best model by validation accuracy.
  - returns 8 values:
    - accuracy: `ID`, `OOD MEAN`, `OOD WORST`, `OOD STD`
    - F1: `ID`, `OOD MEAN`, `OOD WORST`, `OOD STD`
  - computes OOD STD per repeat across OOD environments, then averages across repeats.
- `src/utils.py`
  - `plot_training_curves` now includes F1 summary metrics in the title.
  - train/validation F1 curves are plotted in the same subplot as train/validation
    accuracy.
- Updated all `run_*.py` entrypoints to unpack and print the 8 returned metrics.
