# 2026-06-30

## Small-LR Patience Sweep with Curves and SHAP

Goal: check whether smaller learning rates make `mlp_ce`, `fitce`, and `laat`
comparisons more stable, and verify whether small-gradient settings make SHAP
diagnostics hard to generate or read.

This sweep is separate from the 2026-06-29 patience-only sweep. The earlier
sweep used the previous default learning rate; this sweep only tested smaller
learning rates.
