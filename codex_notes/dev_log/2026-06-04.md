## WHYSHIFT Benchmark Integration

Goal: add the WHYSHIFT benchmark's Taxi and US Accident datasets while keeping
the project runner structure method-centric instead of dataset-specific.

### Implemented

- Added WHYSHIFT dataset code under `data/whyshift/`.
- Added two datasets only:
  - `taxi`
  - `accident`
- Added shared benchmark metadata and result paths through `src/benchmark_config.py`.
- Renamed active runners from ACS-specific names to method-centric names:
  - `run_mlp_ce.py`
  - `run_fitce.py`
  - `run_laat.py`
  - `run_llm_select.py`
  - `run_llm_lasso.py`
  - `run_linear.py`
- Active runners now support:
  - `--benchmark acs`
  - `--benchmark whyshift`
  - `--benchmark synthetic_ood`
- Archived the old `run_synthetic_ood.py`; active synthetic runs now use the
  method-centric runners with `--benchmark synthetic_ood`.

### WHYSHIFT Dataset Protocol

Raw file layout:

- Taxi raw CSVs: `data/whyshift/taxi/raw/*.csv`
- US Accident raw CSV: `data/whyshift/accident/raw/*.csv`

Taxi:

- Domains are inferred from CSV filenames:
  - `train.csv` maps to `nyc`
  - `{city}_clean.csv` maps to `{city}`
- Current default source domain is `bog`, because the local raw files do not
  include `nyc` / `train.csv`.
- Test domains are inferred from available Taxi raw files and exclude the source
  domain.
- Static feature index:
  - `month`
  - `week`
  - `weekday`
  - `hour`
  - `minute_oftheday`
  - `distance`
  - `direction`
- Binary label:
  - `trip_duration >= 900`

US Accident:

- Current source domain is `CA`.
- Test domains are the supported WHYSHIFT state list excluding `CA`:
  - `TX`, `FL`, `OR`, `MN`, `VA`, `SC`, `NY`, `PA`, `NC`, `TN`, `MI`, `MO`
- Explicit 45-feature index is stored in `data/whyshift/config.py` after
  WHYSHIFT-style preprocessing and one-hot encoding, so GPT ranking can use
  fixed feature names.
- The loader validates that the raw CSV/preprocessing output still matches the
  configured feature names.
- Binary label:
  - keep `Severity` 2 and 3 only
  - map `2 -> 0`, `3 -> 1`

Both WHYSHIFT datasets are binary classification tasks, so no multiclass changes
are needed for the current MLP / loss / metric stack.

### Size Defaults

Added shared data-size controls to all benchmark runners:

- `MAX_TRAIN_VAL_SIZE` / `--max-train-val-size`
- `MAX_PER_TEST_SIZE` / `--max-per-test-size`

Unset values use benchmark defaults. Explicit `0` disables that cap.

Default caps:

| benchmark / dataset | `MAX_TRAIN_VAL_SIZE` | `MAX_PER_TEST_SIZE` | reason |
|---|---:|---:|---|
| ACS | 10000 | 0 | 1-repeat MLP CE screen showed no clear degradation on large ACS tasks |
| WHYSHIFT `taxi` | 8000 | 8000 | aligns with WHYSHIFT sampled source/target-domain protocol |
| WHYSHIFT `accident` | 8000 | 8000 | aligns with WHYSHIFT sampled source/target-domain protocol |
| synthetic OOD | 0 | 0 | keep synthetic default sizes unchanged |

The ACS screen used `MAX_TRAIN_VAL_SIZE=10000`, `MAX_PER_TEST_SIZE=0`, and
`REPEAT=1` on the ACS tasks whose original train/validation source data exceeded
10000 rows.

### Paper Alignment Notes

- WHYSHIFT Taxi and US Accident use binary classification in the official code.
- The 8000/8000 default caps follow the WHYSHIFT supplement's sampled
  source/target-domain protocol for Taxi and US Accident.
- Local Taxi defaults to `bog` as source because NYC raw data is not currently
  present. To match a NYC-source setup, add `train.csv` / NYC raw data and update
  the Taxi source domain.
- US Accident currently uses `CA` as source and multiple held-out WHYSHIFT states
  as test domains. This is a multi-target state-shift setup; a single-pair setup
  such as `CA -> OR` can be configured later if needed for a stricter
  paper-matched comparison.
