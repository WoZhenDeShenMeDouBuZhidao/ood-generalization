### Code Notes

- `src/loss.py`
  - 所有 loss class 都支援 `reweighting: bool = False`。
  - `CrossEntropyCELoss(reweighting=True)` 使用 batch 內 present classes 的 class-balanced CE：
    - 先用完整 batch forward 一次，保留 `BatchNorm1d` 的 batch statistics 行為。
    - 再用 per-sample CE 按 ground-truth class 分組，各 class mean 後再平均。
  - regularized losses 也採用完整 batch forward，再對可按 sample 定義的 loss / metric terms 做 present-class 平均。
  - 原先 class-subset forward 會在 minority class count 為 1 時讓 `BatchNorm1d` 報錯，因此已改掉。
- `src/main.py`
  - `LOSS_NAME="cross_entropy"` 會把 `LOSS_KWARGS` 傳給 `CrossEntropyCELoss`。

Conclusion:

- 在 pure CE 下，`resampling` 和 `reweighting` 都能大幅提升 OOD：
  - `OOD MEAN` 約提升 `+0.052` 到 `+0.053`
  - `OOD WORST` 約提升 `+0.099` 到 `+0.107`
- 兩者都會犧牲 ID accuracy，約 `-0.059` 到 `-0.067`。
- `reweighting` only 的 `OOD WORST = 0.7232` 是四組最高。
- `resampling` only 的 `OOD MEAN = 0.7594` 是四組最高。
- `resampling+reweighting` 沒有疊加效果；平均 OOD WORST 低於任一單獨方法，主要受 seed `38224` 的低 OOD WORST 影響。
- 後續若要比較 feature-prior losses，應把 CE balancing baselines 作為必要對照，否則可能把 label imbalance effect 誤判成 feature-ranking effect。
