# Categorical-Feature Removal Diagnosis

## Goal

Test whether categorical features are responsible for FITCE still trailing CE
even when the selected GPT prior has a high empirical percentile against random
rankings. The diagnosis includes three integer-encoded negative-gap cases and
two native one-hot positive controls.

The primary quantity is a paired difference-in-differences:

```text
full gap = FITCE_full - CE_full
numeric-only gap = FITCE_numeric-only - CE_numeric-only
improvement = numeric-only gap - full gap
```

A positive improvement means categorical removal improves FITCE relative to CE.
The existing random-ranking PR is used only to select strong GPT priors; it is
not recomputed or interpreted as a PR in the changed numeric-only feature space.

## Protocol

- Full-feature references use current reproducible CE and explicit
  `grad_alignment_top_p=1.0` FITCE results.
- Numeric-only removes semantic feature types `categorical`,
  `ordinal_categorical`, and `boolean_categorical`. Every model column of a
  removed one-hot semantic group is removed together.
- Rank-weight priors preserve the relative GPT ordering among surviving
  features and recompress it to `1..k`; direct-score priors preserve their GPT
  scores.
- FITCE otherwise retains the active configuration: auto encoding, semantic
  expansion `split`, model-space gradient alignment, `importance_scale=train_std`,
  `reg_scale=0.1`, `tau=2`, class reweighting with scope `all`, the gradient
  term only, and all surviving features in the alignment target.
- CE and FITCE use three matched repeats with seeds `9803`, `38224`, and `8113`.
  All ten numeric-only results passed result, feature-count, seed, loss, and
  recompressed-rank validation.
- Parentheses after an improvement report how many of the three paired repeats
  had a positive improvement.

## Findings

- Categorical removal does not consistently improve FITCE relative to CE.
  The all-five improvement is slightly negative for both ID and OOD.
- Health Insurance shows a stable ID repair (`+0.02070`, 3/3 repeats), but its
  OOD gap slightly worsens. Mobility improves on average, but its OOD result is
  positive in only 1/3 paired repeats.
- Public Coverage OOD worsens in all three repeats. The two one-hot controls
  also disagree across ID and OOD, providing no encoding-wide improvement.
- The ablation is deliberately strong: only two to four model features remain
  in four of the five datasets. Large absolute task changes make a relative-gap
  improvement suggestive rather than sufficient evidence of a FITCE mechanism.

## Decision

Continue using all features and `grad_alignment_top_p=1.0` by default. The
results do not support categorical-feature handling as the general explanation
for FITCE underperforming CE under otherwise strong GPT priors. A more direct
follow-up should keep categorical inputs available to the model and CE term
while changing only how the FITCE gradient regularizer treats them.
