### Notes And Settings

- `synthetic_ood` has one OOD test environment, so `OOD MEAN` and `OOD WORST`
  are identical for the reported averages.
- For ACS tasks, `CrossEntropyLoss original setting` is the initial plain baseline:
  MLP without `BatchNorm1d`, no class reweighting, no resampling, and no standardization.
- `CrossEntropyLoss fix dataset issue` records the fixed baseline after dataset-specific
  issues were diagnosed:
  - `acsincome`: class reweighting.
  - `acsemployment`, `acsemploymentfiltered`, `acsmobility`: default MLP with
    `BatchNorm1d`.
  - `acsincomepovertyratio`: default MLP with `BatchNorm1d` and class reweighting.
  - `acshealthinsurance`: default MLP with `BatchNorm1d`, remove `ST`.
  - `acspubliccoverage`: default MLP with `BatchNorm1d`, remove `ST`.
  - `acstraveltime`: default MLP with `BatchNorm1d`, remove `PUMA`, `ST`, and
    `POWPUMA`.
- All `CrossEntropyLoss fix dataset issue` ACS numbers use the same full baseline setting as
  ACSIncome: `TRAIN_BATCH=256`, `EVAL_BATCH=2048`, `LR=1e-4`, `PATIENCE=500`,
  `REPEAT=5`, `MAX_EPOCHS=5000`, and seeds
  `[9803, 38224, 8113, 4854, 98825]`.
- `FeatureImportanceTargetCELoss` is summarized as one method group. On
  `synthetic_ood`, it uses perfect feature ranking. On real ACS datasets, feature ranking
  is obtained from GPT; the current public benchmark has confirmed this loss on
  `acsincome`, while the other ACS task entries are left as `--` until evaluated.

### FeatureImportanceTargetCELoss Settings

- Shared loss parameters unless otherwise stated:
  - model: `MLP`
  - seeds: `[9803, 38224, 8113, 4854, 98825]`
  - `grad_scale=2.0`
  - `weight_scale=3.0`
  - `suppress_scale=6.0`
  - `target_power=1.0`
- `synthetic_ood`:
  - ranking source: perfect known synthetic feature ranking
  - feature weights: `causal_main=3`, `causal_aux=2`,
    `noise_1/2/3=1`, `spurious_main=0`
  - `REG_SCALE=0.5`
- `acsincome`:
  - ranking source: GPT structured score ranking
  - train/validation state: `PR`
  - OOD tests: 46 held-out states
  - raw inputs with `DATASET_CONFIG={"resampling": False, "standardize": False}`
  - class-balanced CE term with `reweighting=True`
  - structured GPT score weights:
    `SCHL=9`, `WKHP=8`, `OCCP=8`, `AGEP=7`, `COW=6`,
    `MAR=5`, `RELP=4`, `POBP=3`, `SEX=2`, `RAC1P=1`
  - `REG_SCALE=1.0`
  - `importance_scale="train_std"`
- Other ACS tasks:
  - ranking source should be GPT, matching the ACSIncome protocol.
  - benchmark entries remain `--` until those task-specific GPT-ranking experiments are run.
