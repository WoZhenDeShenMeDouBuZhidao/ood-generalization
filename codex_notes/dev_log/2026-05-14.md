# Dev Log: 2026-05-14

## ACS GPT Score-All Ranking

Goal:

- Add a fourth GPT feature-ranking method, `score_all`.
- `score_all` is score-style self-consistency, but each LLM call scores every feature
  in one response instead of scoring one feature per call.
- Generate `score_all` rankings and token usage for all 8 ACS tasks.

Implementation:

- Extended `rank_features.py`:
  - added `build_score_all_prompt`.
  - added `validate_score_all_payload`.
  - added `generate_score_all`.
  - added CLI support for `--method score_all`.
  - updated `--method all` and dry-run printing to include `score_all`.
- Output file pattern:
  - `acs_tasks/<dataset>/rankings/gpt-5.5_score_all_feature_ranking.json`
- Output schema matches the existing score-style artifacts:
  - method-level `token_usage`.
  - raw `llm_calls`.
  - final `response.ranking`.
  - per-feature mean/std score summaries.
  - raw all-feature sample payloads under `response.samples`.

Run:

- Initial API attempt on 2026-05-13 failed before writing files because the provider
  returned `auth_unavailable` for `gpt-5.5`.
- Retried on 2026-05-14 and completed all tasks:
  - `python rank_features.py --dataset all --method score_all --score-samples 5 --score-temperature 0.5 --call-delay 1 --max-retries 2 --retry-sleep 120 --skip-existing`
